⚠️ 既知の非対応・検証対象外(バグではなく仕様上の理由)
  • $document(素の、popup/popunder以外): メインフレーム自体の読み込みを 通常のネットワークフィルタでは対象外にしている(ページ全体が壊れることを避ける、 WebViewベースの広告ブロック実装で広く採られている標準的な方針)ため、意図的に ネットワークブロックとしては機能しません。
  • $cname: 実際にCNAMEクローキングされた計測ドメインが無いと再現できないため、 この静的なテストページの構成だけでは自動検証できません。
  • $csp= / $replace= / $uritransform=: 該当ルールは パース時に安全に読み飛ばされる(=無視される)未対応オプションです。
  • $strict1p / $strict3p: 同一の実効ドメイン配下に複数ホスト名 (サブドメイン)を用意できない現在のホスティング構成では、通常の $third-party/$first-partyとの挙動差を実演できません。
  • 生の正規表現フィルタ(/pattern/形式)は非対応です。
  • MyBrowser独自(本家uBOと差がある): trusted-*は本家では信頼済みリスト限定ですが、 MyBrowserは信頼制限なしで動作します。rmnt/rpnt/trusted-rpntは 本家仕様(nodeNameは実タグ名/正規表現でDOM全体をtreewalker走査)にMyBrowserがまだ対応しておらず、 現状CSSセレクタとして扱っています(既知の課題)。
